# RPA 给客户发消息 Demo

## 背景

- **来源**: 用户需求，做一个**专门独立的 demo**，通过 RPA（七小饱）实现「给客户发消息」的能力。
- **现状**:
  - 已分析 mgvopen MR 215（`feat/rpa-conversation-orchestration`）的 RPA 接入实现，是本 demo 的参考蓝本。
  - RPA 平台 = **七小饱**，API 文档 `~/Downloads/qixiaobaoapidoc.md`，开发环境 base `http://192.168.2.153:9080`。
  - demo 落点 = `~/Documents/sop-mini/`：后端 `sop-mini-api-on-premise`(FastAPI)，前端 `sop-mini-web-on-premise`(React19+TS+Vite+shadcn/ui)。
- **痛点**: mgvopen 全链路重（ai-sop+mgvcore+落库），且 RPA 回调密钥尚无真实值；需要**独立、可本地演示、mock 优先**的 demo 来验证「RPA 给客户发消息」整条通路。

## 目标（用户视角）

- 客户发消息 → RPA 回调 → demo 验签解密 → AI 生成话术 → demo 回发 RPA → 客户收到回复，**全闭环可演示**。
- 内置**模拟 RPA 控制台**，无七小饱密钥也能本地跑通（mock 优先，留真实配置位）。
- React **监控页**实时展示「客户消息 → AI 分析 → 话术回发」闭环（SSE 推送）。
- 会话/消息/客户数据落库（SQLite），重启不丢。
- 架构贴合 sop-mini 现有 FastAPI/React 规范，最小改动、尽量精简。

## 范围

### 在范围内（In Scope）
- FastAPI 回调接收端点（验签 + AES-CTR 解密 + zstd 解压 + 解析）
- LLM 话术生成（直连通用 LLM，如 OpenAI/DeepSeek 兼容接口）
- SQLite 落库（会话 / 消息 / 客户）
- SSE 推送（后端 → React 监控页）
- 模拟 RPA 控制台（前端表单模拟客户发消息 → 触发回调）
- 真实 RPA 出站发送封装（token 获取+缓存+提前刷新+429 退避，可开关切 mock/real）
- 配置走环境变量 + 配置文件

### 不在范围内（Non-Goals）
- 登录/权限/多租户
- 配置管理页面（改配置走 env/配置文件）
- 群聊（is_room）支持
- 图片/语音/视频等富媒体消息（先只做文本）
- 对接 mgvcore / ai-sop-api 落库
- 生产部署（on-premise 部署是后续迭代）

## 约束

- 后端必须 **Python (FastAPI)**，前端必须 **React**，贴合 sop-mini 现有栈。
- 不引入新的常驻服务（demo 单进程可跑）。
- 验签/解密算法必须与七小饱文档一致（HMAC-SHA256 / AES-CTR / zstd），mock 和 real 共用同一套加解密。
- 密钥**绝不入库**，只走环境变量/配置文件。

## 已讨论的方案

### 方案 A：内置模拟 RPA 控制台（已选 ✓）
- **核心思路**: demo 内置「模拟客户」+「模拟 RPA 回调」，前端表单发消息直接触发 demo 内部回调，跑通全链路；同时留真实 RPA 适配层，拿到密钥后一键切真实。
- **优点**:
  - 无七小饱密钥也能完整演示
  - 一套代码同时覆盖 mock/real，加解密逻辑唯一
- **缺点**:
  - 需要实现一套 RPA 加解密（mock 也要走同一加密链路才能验证）
  - 真实链路（真客户消息进来）需等密钥到位后联调
- **工作量**: 中

### 方案 B：独立模拟回调脚本
- **核心思路**: 另起一个脚本模拟七小饱回调（带真实加密报文）。
- **优点**: 更接近真实回调报文格式
- **缺点**: 多一个组件，演示体验割裂，仍需额外 mock 前端
- **驳回理由**: 用户选了方案 A（内置控制台，演示即开即用）

## 成功标准

- [ ] `python -m uvicorn` 起后端，`npm run dev` 起前端
- [ ] 前端模拟客户发消息 → 后端收到加密回调 → 验签通过 → 解密成功 → LLM 返回话术 → 落库 → SSE 推送 → 前端监控页实时显示完整闭环
- [ ] 会话/消息落 SQLite，重启后监控页可查历史
- [ ] 加解密有单测（用文档 Java 示例/自构造向量验证 HMAC/AES-CTR/zstd 往返）
- [ ] mock 模式不出网（不真调七小饱）；切换 real 模式后走真实 token+发送

## 待解决问题
